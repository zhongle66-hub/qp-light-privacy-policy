1. 引言

本隐私政策由 深圳市潜派创新技术有限公司（以下简称"我们"）制定并发布，适用于我们开发并运营的移动应用程序 QPLight（以下简称"本应用"）。我们深知个人信息对您的重要性，并致力于保护您的隐私安全。

请您在使用本应用前仔细阅读并充分理解本政策。您开始使用本应用，即表示您已阅读、理解并同意本政策的全部内容。如您不同意本政策的任何内容，请停止使用本应用。

核心说明：本应用为纯离线单机应用。
  • 本应用不申请网络访问权限（android.permission.INTERNET），在操作系统层面即不具备任何联网能力
  • 本应用不设服务器，无域名、无接口地址，不会向任何服务器传输数据
  • 本应用不收集您的任何个人身份信息
  • 本应用未集成任何数据统计、用户行为分析、消息推送、广告投放或崩溃收集组件

2. 我们收集的信息

2.1 您主动提供的信息

我们不收集您通过本应用主动提供的任何个人信息。本应用无需注册、无需登录、无需创建账户，不会要求您提供姓名、手机号码、电子邮箱、身份证件号码等任何信息。

2.2 本应用不收集的信息

本应用不会收集、存储或传输下列任何信息：

  • 个人身份信息：姓名、手机号码、电子邮箱、身份证件号码、人脸信息等
  • 地理位置信息：不读取、不记录、不上传您的真实地理位置
  • 通讯录、短信、通话记录
  • 相册、文件、麦克风及摄像头内容
  • 用于追踪或用户画像的设备标识符
  • 应用安装列表
  • 应用使用行为数据、页面埋点数据
关于设备信息的说明：本应用会读取设备的基础标识信息（Android 系统为 ANDROID_ID，iOS 系统为 identifierForVendor）， 其唯一用途是在您的设备本地生成固定的灯具控制地址（RF297L 协议地址），以确保同一台手机对同一组灯具的控制地址保持稳定。 该信息仅在本机进行计算与存储，不会上传至任何服务器，不会用于识别您的真实身份，也不会用于追踪或用户画像。

您在本应用中设置的灯光参数（包括颜色、亮度、色温、灯具分组名称、定时设置、语言偏好等）默认保存在您设备的本地存储中，仅用于恢复您的使用偏好。这些数据不会离开您的设备，卸载本应用即会一并删除。

3. 我们如何使用信息

本应用对上述权限与本地数据的使用，仅限于实现下列功能：

  • 搜索、连接并控制您附近的智能照明设备
  • 实现灯光控制功能（开关、亮度、颜色、色温调节）
  • 在本地保存您的灯具配对信息与偏好设置
  • 在本地生成并管理灯具控制地址

我们不会将任何信息用于广告投放、用户画像、行为分析或任何与上述功能无关的用途。

4. 信息的存储与安全

4.1 本地存储

本应用产生的全部数据均存储在您的设备本地，包括：

  • 灯具配对信息（灯具分组名称、控制地址）
  • 用户偏好设置（亮度、颜色、色温、定时、语言）
  • 应用基础配置

4.2 无服务器通信

本应用不具备联网能力，因此：

  • 不会向任何外部服务器上传数据
  • 不会与任何第三方服务共享数据
  • 不使用云存储或数据同步功能
  • 不会出于广告目的追踪用户行为
  • 不存在将您的信息上传至任何云端服务器的情况

本应用与灯具之间的通信仅通过蓝牙低功耗（BLE）广播完成，属于短距离本地射频通信，不经过互联网，也不经过任何中间服务器。

4.3 信息安全

本应用不进行任何数据传输与云端存储，您的信息不存在因网络传输或服务器存储而被泄露、篡改或丢失的风险。存储在设备本地的数据受操作系统自身的应用沙箱机制保护，其他应用无法读取。

5. 第三方服务与开源组件

本应用未集成任何第三方数据统计、用户行为分析、消息推送、广告投放或崩溃收集服务。本应用不含任何广告。

  • device_info_plus —— 读取设备基础标识，用于在本地生成固定的灯具控制地址

Privacy Policy

1. Introduction

This Privacy Policy is issued by Shenzhen Qianpai Innovation Technology Co., Ltd. ("we," "our," or "us") and applies to our mobile application QPLight (the "App"). We are committed to protecting your privacy.

Please read this policy carefully before using the App. By using the App, you acknowledge that you have read, understood, and agreed to this policy. If you do not agree with any part of it, please stop using the App.

Key Point: The App is a fully offline, standalone application.
  • The App does NOT request network access permission (android.permission.INTERNET), and therefore has no network capability at the operating system level
  • The App has no server, no domain, and no API endpoint, and never transmits data to any server
  • The App does NOT collect any personally identifiable information
  • The App contains no analytics, behavioral tracking, push notification, advertising, or crash-reporting components

2. Information We Collect

2.1 Information You Provide

We do NOT collect any personal information you voluntarily provide through the App. The App requires no registration, no login, and no account creation. It never asks for your name, phone number, email address, ID number, or any similar information.

2.2 Information the App Does NOT Collect

The App does NOT collect, store, or transmit any of the following:

  • Personal identifiers: name, phone number, email, ID number, facial data, etc.
  • Geographic location: your real location is never read, recorded, or uploaded
  • Contacts, SMS, or call logs
  • Photos, files, microphone, or camera content
  • Device identifiers used for tracking or profiling
  • Installed application lists
  • App usage or behavioral analytics data
About device information: The App reads a basic device identifier (Android: ANDROID_ID; iOS: identifierForVendor) for the sole purpose of generating a stable light-control address (RF297L protocol address) locally on your device, ensuring that the same phone keeps a consistent control address for the same set of lights. This information is computed and stored only on your device. It is never uploaded to any server, never used to identify you, and never used for tracking or profiling.

3. How We Use Information

Use of the permissions and local data described above is limited strictly to the following:

  • Discovering, connecting to, and controlling nearby smart lighting devices
  • Providing lighting control (power, brightness, color, color temperature)
  • Saving your pairing information and preferences locally
  • Generating and managing light-control addresses locally

We do NOT use any information for advertising, profiling, behavioral analysis, or any purpose unrelated to the functions above.

4. Data Storage and Security

4.1 Local Storage

All data generated by the App is stored locally on your device, including:

  • Lighting device pairing information (group names, control addresses)
  • User preferences (brightness, color, color temperature, timers, language)
  • Basic application configuration

4.2 No Server Communication

Because the App has no network capability, it:

  • Never uploads data to any external server
  • Never shares data with any third-party service
  • Uses no cloud storage or synchronization
  • Never tracks user behavior for advertising
  • Has no means of transmitting your information to any server

Communication between the App and lighting devices occurs exclusively via Bluetooth Low Energy (BLE) advertising — a short-range local radio link that does not traverse the internet or any intermediary server.

4.3 Data Security

Since the App performs no data transmission and no cloud storage, your information is not exposed to risks associated with network transmission or server-side storage. Data stored locally is protected by the operating system's application sandbox, which prevents other apps from reading it.

5. Third-Party Services and Open-Source Components

The App does NOT integrate any third-party analytics, behavioral tracking, push notification, advertising, or crash-reporting services. The App contains no advertising.

The App uses the following open-source components solely for core functionality. None involve collection or upload of personal information:

  • flutter_blue_plus — Bluetooth communication capability
  • permission_handler — requesting permissions required for operation
  • shared_preferences — storing app preferences locally
  • device_info_plus — reading a basic device identifier to generate a stable light-control address locally
